# 몬스터 퀘스트 v0.1

모둠 친구 **모두가** 문제를 해결해야 몬스터를 공격할 수 있는 협동형 수학 퀴즈입니다.
선생님 화면과 학생 화면이 실시간으로 연결됩니다.

## 들어 있는 것 (v0.1)

- 선생님: 단원·라운드 수·모둠 인원 고르기 → 방 만들기(QR, 방 번호 4자리) → 대기 명단 → 게임 시작 → 모둠 현황 보기 → 모두 멈추기(Freeze) → 끝내기
- 학생: QR로 들어오기(로그인 없음, 번호+이름) → 대기실 → 3·2·1 → 내 문제 풀기 → 모둠 모두 해결하면 공격 버튼 열림 → 몬스터 처치 → 다음 몬스터
- 문제: 6학년 1학기 수학 3단원(분수의 나눗셈, 각기둥과 각뿔, 비와 비율) 각 10문제. 보기 순서는 매번 섞입니다.
- 새로 고침해도 같은 자리로 돌아옵니다(교사·학생 모두).

## 폴더 안내

| 위치 | 하는 일 |
|---|---|
| `shared/questions.js` | 문제 은행. 문제를 고치거나 늘릴 때 여기만 고치면 됩니다. |
| `shared/engine.js` | 게임 규칙(공격 조건, 모둠 나누기 등) |
| `server.js` | 교사·학생 화면을 이어 주는 서버 |
| `public/teacher.html` | 선생님 화면 |
| `public/student.html` | 학생 화면 |
| `public/demo.html` | 서버 없이 해 보는 체험판 |
| `test/` | 규칙이 제대로 동작하는지 자동 검사 |

## 교사 PC에서 켜기

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다(처음 한 번).
2. 이 폴더에서 터미널(명령 프롬프트)을 열고 `npm install` (처음 한 번)
3. `npm start`
4. 화면에 나온 주소로 교사 PC에서 `teacher.html`을 엽니다. 학생은 QR을 찍습니다.
   - 학생 기기가 교사 PC와 **같은 와이파이**에 있어야 합니다.
   - 학교망이 기기끼리의 연결을 막으면 접속이 안 될 수 있습니다. 그때는 아래 인터넷 배포를 씁니다.

## 인터넷에 올리기 (Render 예시)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. render.com 가입 → New → Web Service → 저장소 선택
3. Build Command: `npm install`, Start Command: `npm start`
4. 만들어진 주소(예: `https://○○○.onrender.com/teacher.html`)로 접속합니다.
   - 무료 요금제는 한동안 쓰지 않으면 잠들어서 첫 접속이 느릴 수 있습니다.
   - 서버를 다시 켜면 진행 중이던 방은 사라집니다(v0.1은 기록을 저장하지 않습니다).

## 검사 돌리기

`npm test` — 공격 조건, 동시에 누르기, 연결 끊김, 문제 은행 오류 등을 자동으로 확인합니다.
