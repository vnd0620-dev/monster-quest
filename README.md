# 협력 몬스터 퀴즈 v0.17

> "누가 가장 빨리 풀었는가?"가 아니라 "우리 모두가 결국 해결했는가?"

모둠 친구 **모두가** 자기 문제를 해결해야 몬스터에게 합동 공격을 할 수 있는 협동형 수학 퀴즈입니다.
선생님 화면과 학생 화면(태블릿·휴대폰)이 실시간으로 연결됩니다. 학생은 로그인 없이 방 번호와 출석 번호·이름만으로 들어옵니다.

## 단원별 몬스터 (v0.16)

단원마다 4단계로 진화하는 몬스터가 있습니다. 그림은 `public/img/mon/` 에 있습니다. 5학년 단원은 같은 몬스터 6종을 단원 순서대로 다시 씁니다(1단원 용 … 6단원 페가수스).

| 단원 | 1단계 → 2단계 → 3단계 → 4단계(최종 보스) |
|---|---|
| 1. 분수의 나눗셈 | 용콩이 → 비늘드라몬 → 암흑바룡 → 메가워드라몬 |
| 2. 각기둥과 각뿔 | 문어콩 → 옥토바이트 → 크라케노이드 → 심해거수몬 |
| 3. 소수의 나눗셈 | 깃부리 → 그리키드 → 수호그리폰 → 황금뇌수몬 |
| 4. 비와 비율 | 뿔멍이 → 해태치 → 단죄해치몬 → 신갑수호몬 |
| 5. 여러 가지 그래프 | 불사슴 → 화록몬 → 염제기린몬 → 천뇌신록몬 |
| 6. 직육면체의 부피와 겉넓이 | 뽀롱마 → 오로라콘 → 순백천마몬 → 세인트페가몬 |

- 마지막 스테이지는 언제나 4단계(최종 보스)입니다. 그 앞 스테이지는 1 → 2 → 3단계 순서로 나오고, 스테이지가 5개이면 4번째도 3단계입니다.

## 수업 흐름

1. 선생님: 8단계 설정(학년·학기 → 단원 → 평가 요소 → 난이도 → 스테이지 수 → 1인 문제 수 → 레벨 테스트 문항 수 → 모둠 인원)을 모두 확인 → 방 번호·QR 만들기
2. 학생: QR을 찍거나 학생 주소에서 방 번호 입력 → 대기실(상점에서 캐릭터 꾸미기 가능)
3. 레벨 테스트(3·2·1) → 레벨을 고르게 섞어 모둠 구성(설정 인원 ±1명) → 게임 시작(3·2·1)
4. 게임: 내 문제를 맞히면 몬스터에게 데미지. 모둠원 모두 해결하면 합동 공격 → 다음 스테이지(마지막은 최종 보스)
5. 우리 모둠이 최종 보스를 물리치면 '학습 리포트 정리 중' → 학습 리포트 → 오답노트 다시 풀기 → 처음 화면

## 주요 기능

- **내 힌트(자동)**: 1번 틀리면 1차 힌트, 2번 틀리면 AI 힌트, 3번 틀리면 해설. 틀린 문제는 오답노트에 자동 저장
- **친구 힌트(모둠 힌트 상자)**: 먼저 다 푼 학생이 추가 문제(난이도 상·중·하 선택)를 맞히면 힌트를 만들어 상자에 넣음
  - 힌트 3종류(틀린 보기 지우기 · 개념 힌트 · 풀이 과정 살펴보기)를 골고루 만들어야 함
  - 상자는 스테이지마다 새로 시작, 최대 10개. 종류별 한도: ✂️ 보기 지우기 2개 · 📗 개념 4개 · 🪜 풀이 4개 (학생 화면에 "✂️ 1/2"처럼 표시). 다 차면 추가 문제는 포인트만 받음
  - 쓸 수 있는 때: ✂️ 틀린 보기 지우기는 귀한 힌트라 1번 틀리면, 나머지는 2번 틀리면(또는 60초 경과). 한 문제에 1개만 사용. 누가 만들었는지는 보이지 않음
- **오답노트 그림 크게 보기**: 문제 그림을 누르면 화면 가득 확대
- **추가 문제**: 주관식. 답 모양에 맞는 칸(분수·대분수·소수·비·백분율·숫자) 제공. 모르면 '오답노트에 저장하고 나가기'
- **반응·손들기(줌 방식)**: 이모지는 프로필 오른쪽 위에 10초 표시(하나만), 손들기는 이름 왼쪽 ✋ + 반짝임. 선생님이 손을 내려 줄 수 있음
- **게임 설명 팝업**: 학생이 대기실에 처음 들어왔을 때 한 번만 뜸(게임 중간에 들어오면 안 뜸, 새로 고침해도 다시 안 뜸). 대기실·입장 화면의 '게임 방법' 버튼으로 다시 보기
- **가상 친구**: 선생님 대기실에서 '🤖 가상 친구 ○명 넣기'. 레벨이 고르게 나오고, 게임 중에는 실제 레벨에 맞춰 풀어요(레벨 4는 한 문제 7초쯤, 레벨 1은 20초쯤). 게임 중 '🤖 가상 친구 모두 완료'로 이번 스테이지 문제를 한 번에 끝낼 수 있음. 학생 화면에는 🤖로 표시되고, 협력 리포트·엑셀에는 들어가지 않음(실제 학생이 가상 친구 힌트를 쓴 횟수만 따로 표시)
- **선생님 화면**: 모둠 현황, 도움이 필요한 학생 표시, Freeze(모두 멈춤), 학생 이름을 누르면 성취기준별 리포트·문항별 기록·오류 유형
- **학습 리포트**: 평가 요소마다 한 줄씩 — 수준(학생 화면은 쉬운 말) → 영역 → 개념 정리 → 자주 한 실수 → 다음에 해 볼 것
- **상점**: 문제를 맞히면 포인트. 캐릭터·모자·안경(하트 선글라스·별 안경·3D 안경·무지개 안경·파티 고양이 안경 추가)·무기·친구·배경 꾸미기
- **협력 리포트(연구용)**: 선생님 화면의 '📊 협력 리포트' 버튼. 요약·레벨 집단 비교·모둠별·설문·학생별·힌트 주고받기 표를 보고, '학생 리포트 내려받기'로 엑셀 파일 1개(시트 6개)에 한꺼번에 내려받기
  - 대기실로 돌아가도 바로 전 게임 리포트는 볼 수 있음. '새 수업 만들기'를 누르거나 서버가 다시 켜지면 사라지므로 **수업이 끝나면 바로 내려받으세요.**
- **게임 끝 설문**: 리포트를 보기 전에 3~5문항(😀 그렇다 / 🙂 보통이다 / 😐 아니다). 힌트를 받은 학생·만든 학생에게만 맞는 문항이 나옴
- **스테이지별 몬스터**: 새끼 → 성장 → 최종 보스(불꽃 기운·왕관)로 점점 강해지는 모습

## 코드를 고친 뒤 반영하기

1. 새로 받은 파일을 GitHub 저장소에서 **Add file → Upload files**로 올리고 **Commit changes** (이름이 같은 파일은 덮어써짐)
2. Render가 자동으로 다시 배포합니다(1~2분). Render 화면에서 **Live**가 뜨면 끝

## 교사 PC에서 직접 켜기 (인터넷 배포 없이)

1. [Node.js](https://nodejs.org) LTS 버전 설치(처음 한 번)
2. Windows는 `start-windows.bat`, Mac은 `start-mac.command`를 더블클릭
3. 선생님 화면이 자동으로 열립니다. 학생 기기는 **같은 와이파이**에 있어야 하며, 학교 와이파이가 기기끼리 연결을 막으면 접속되지 않을 수 있습니다.
